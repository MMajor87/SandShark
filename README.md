# SandShark

SandShark is a private-for-now Windows desktop client project for Sharkord.

The goal is to reuse the existing Sharkord React/TypeScript frontend while adding Electron-based desktop functionality, including native notifications, tray behavior, push-to-talk, Windows startup options, local configuration, and installer/update support.

## Current Status

This repository is initialized as the SandShark project shell. The implementation plan lives in [Sharkord_Desktop_Fork_TODO.md](./Sharkord_Desktop_Fork_TODO.md).
