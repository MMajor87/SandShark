# SandShark branding

SandShark is the selected fork and Windows executable name. The packaged desktop client uses `sandshark.png` for the application window, installer, and tray icon, and `com.sandshark.desktop` remains its application identifier.

SandShark is the name of the desktop client, the web client and the server. User-facing text uses **SandShark**; identifiers, environment variables (`SANDSHARK_*`), storage keys, data folders, deep links (`sandshark://`) and release assets use `sandshark`.

The project began as a fork of an MIT licensed project. Its copyright notice stays in `LICENSE`, as the license requires.
