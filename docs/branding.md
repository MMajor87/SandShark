# SandShark branding

SandShark is the selected fork and Windows executable name. The packaged desktop client uses `sandshark.png` for the application window, installer, and tray icon, and `com.sandshark.desktop` remains its application identifier.

Desktop-facing titles and the About row identify SandShark as a Sharkord-compatible desktop client. References to Sharkord remain where they identify the independent server project, its protocol compatibility, or upstream attribution; SandShark does not present itself as the Sharkord server product.

The project retains the upstream license and attribution. Before public distribution, review the upstream project's current branding and trademark guidance alongside the release materials.
